I am a **Backend Developer** passionate about building **scalable**, **secure**, and **maintainable web applications** using modern backend technologies.

My primary expertise includes **Java, Spring Boot, Python, Django, FastAPI, REST APIs, and database management**.

I enjoy developing:

- **Web Applications and REST APIs**,
- **Microservices and Backend Services**,
- **Authentication and Authorization Systems**,
- **Database-driven Applications**,
- **AI-powered Applications using LLMs and Spring AI**,
- **Dockerized Backend Applications**.

I continuously explore new technologies, especially **System Design, Generative AI, AI Agents, and RAG**.

### Java

Java is my primary programming language for developing **backend applications**, **REST APIs**, and **web services**.

I work with **Core Java, OOP, Collections, Streams, Exception Handling, Multithreading, and Java 8+ features**.

I primarily use Java with **Spring Boot, Spring MVC, Spring Security, Spring Data JPA, and Hibernate**.

### Spring Boot

Spring Boot is my go-to framework for building **RESTful APIs, backend applications, and microservices**.

I have worked with **Spring MVC, Spring Security, Spring Data JPA, Hibernate, Spring Cloud, and Spring AI**.

I use Spring Boot for **JWT authentication, role-based authorization, database integration, validation, exception handling, and layered architecture**.

### Python

Python is another important language in my backend development toolkit.

I have experience building backend services and REST APIs using **Django, Django REST Framework, and FastAPI**.

I also use Python for exploring **AI applications, LLM integration, and automation**.

### SQL

SQL is an essential part of my backend development workflow.

I primarily work with **PostgreSQL and MySQL** for relational database management, writing queries, managing relationships, and data persistence.

I use **Spring Data JPA, Hibernate ORM, and Django ORM** for database operations.

### Authentication and Security

I have experience implementing secure authentication and authorization mechanisms using **Spring Security, JWT, OAuth 2.0, BCrypt, and Role-Based Access Control (RBAC)**.

I have also worked on **authentication integration, token validation, API security, and multi-tenant backend systems**.

### Generative AI and Spring AI

I am actively exploring **Generative AI, Large Language Models (LLMs), Spring AI, AI Agents, and Retrieval-Augmented Generation (RAG)**.

I have worked with **Spring AI ChatClient, LLM APIs, Prompt Engineering, and conversation management** to build AI-powered backend applications.

### Amazon Web Services

I have explored **AWS cloud services** including **EC2, S3, RDS, IAM, and CloudWatch**.

I also use **Docker, Linux, Ubuntu, Git, and GitHub** for application development, containerization, and deployment.
